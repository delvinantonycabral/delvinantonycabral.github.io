01 / Systems & development

KernelLab

Work in progress

A Windows-based environment concept for testing operating-system kernels in an emulator without replacing the computer's existing operating system.

Explored technologies: Flutter, Dart, Windows and QEMU.

Planned areas include kernel-image handling, emulator workflows and diagnostic output. Only features verified in the current build should be described as implemented.

02 / Hardware & visualisation

Smart Sonar System

Demonstration project

An Arduino-based scanning and detection demonstration combining an ultrasonic sensor, a servo motor and a browser-based radar-style visualisation.

Components: Arduino Uno, HC-SR04 sensor and SG90 servo.

Software: HTML, JavaScript and Canvas.

The demonstration uses an air ultrasonic sensor; it should not be presented as a fully functional underwater sonar instrument.
