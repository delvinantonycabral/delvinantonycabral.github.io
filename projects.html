KernelLab

A Windows desktop environment concept for safely exploring and testing kernel experiments through virtualisation. The Flutter interface has been set up and QEMU is installed; connecting a real bootable kernel artifact remains part of the work.

What I'm exploring — desktop UI development, emulator workflows, file handling and the relationship between bootable images and virtual machines.

02 / ELECTRONICSDEMONSTRATED

Smart Sonar System

An educational scanning demonstration built with an Arduino Uno, an HC-SR04 ultrasonic sensor and an SG90 servo. A laptop-based HTML Canvas interface visualises the sensor's sweep as a radar-style display.

Important distinction — the HC-SR04 is an air ultrasonic sensor. This is a sonar-inspired scanning demonstration, not a validated underwater detection system.
