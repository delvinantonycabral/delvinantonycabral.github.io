The Problem & Origin

The idea started with a simple, everyday challenge: helping elderly people and grandparents reliably remember when to take their medicines. Many existing health apps are crowded with dense menus, tiny text, and complex settings that create anxiety rather than confidence for older adults.

How the Concept Evolved

What began as a straightforward medicine reminder grew into a broader caregiver-support ecosystem. By combining a calm, high-legibility interface for elderly users with a QR-based caregiver linking concept, family members can help manage schedules and stay connected without forcing seniors to navigate complicated technical setup steps.

Project Context: Developed through product exploration, accessibility thinking, and Flutter UI prototyping. The screens above are original conceptual UI mockups designed to demonstrate the interface direction.

EVOLUTION TIMELINE

  1. Stage 01 · Everyday Observation Identifying friction in daily medication routines for grandparents.
  2. Stage 02 · Reminder Interface Designing large-type, clear dose cards with single-tap confirmation.
  3. Stage 03 · Caregiver Connection Exploring instant QR code pairing between elderly user and caregiver.
  4. Stage 04 · Accessibility Refinement Focusing on calm visual hierarchy, contrast, and low cognitive load.

Purpose & Engineering Motivation

Experimenting with operating-system kernels normally requires tedious command-line emulator flags or carries the risk of misconfiguring a host machine. KernelLab explores a dedicated Windows desktop workbench that streamlines booting and inspecting kernel prototypes safely inside an isolated QEMU virtual machine.

Building KernelLab has been a deep exploration into how desktop applications bridge user-friendly interfaces with low-level emulation workflows, bootloader concepts, and kernel build artifacts.

Current Status: Under active exploration and development. Its emulator execution workflow depends on supplying a compatible kernel or bootable image artifact.

Concept Vision

Inspired by the idea of a personal Jarvis-style assistant, this project explores how a desktop computer can become more responsive and conversational. Rather than relying solely on scattered windows and manual clicks, the concept investigates natural-language command panels and context-aware productivity assistance.

The design deliberately avoids noisy sci-fi clichés in favour of a refined, quiet command interface that respects focus while assisting with everyday tasks.

Project Context: Presented as an ongoing AI assistant concept and human-computer interaction exploration rather than a finished commercial product.

Hardware-Software Integration

Created and successfully presented for my Class 11 science exhibition, the Smart Sonar System was my hands-on introduction to bridging physical electronics with live software visualization.

An Arduino Uno controlled an SG90 servo motor to sweep an HC-SR04 ultrasonic distance sensor across an angular arc, streaming angle and distance readings to a laptop where an HTML Canvas interface plotted detected objects in real time.

Technical Accuracy Note: Inspired by sonar principles, this educational prototype utilized an air-based HC-SR04 ultrasonic sensor for classroom/exhibition distance scanning and visualization rather than deep-water marine mapping.
