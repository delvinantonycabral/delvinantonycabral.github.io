# Delvin Antony Cabral — Personal Website

A dark editorial-style personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — homepage
- `about.html` — about page
- `technology.html` — technologies and areas of learning
- `projects.html` — projects, prototypes and explorations
- `style.css` — shared design system and responsive styles
- `script.js` — mobile navigation and subtle reveal transitions
- `robots.txt` and `sitemap.xml` — search engine discovery

## Publish with GitHub Pages
Repository: `delvinantonycabral/delvinantonycabral.github.io`

In GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
