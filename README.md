# Delvin Antony Cabral — Personal Website

A static personal website built with HTML, CSS and vanilla JavaScript. It is designed for GitHub Pages.

## Files
- `index.html` — homepage
- `about.html` — biography and learning journey
- `technology.html` — technology interests and skills
- `projects.html` — project showcase
- `style.css` — shared design system and page styles
- `script.js` — mobile navigation and decorative radar animation
- `robots.txt` and `sitemap.xml` — search-engine discovery files

## Before publishing
1. Replace `YOUR-USERNAME` in canonical URLs, structured data, `robots.txt` and `sitemap.xml`.
2. Confirm the repository's actual GitHub Pages URL. If the repository is named `username.github.io`, the base URL will usually be `https://username.github.io/` without `/delvin-personal-website/`.
3. Replace social profile and email placeholders in `index.html` with links you are comfortable making public.
4. Verify all project descriptions and statuses. Add only real screenshots, repository links and confirmed features.
5. Test every page locally before publishing.

## Publish with GitHub Pages
1. Put all files in the root of your public repository.
2. Open repository **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for GitHub Pages to publish and open the provided URL.

## Google Search
After the site is live, add the exact website URL to Google Search Console, verify ownership and submit the sitemap. Indexing and search ranking are controlled by Google and are not guaranteed.

## Privacy
Do not publish a home address, phone number, school details or other private information. Use only public contact links approved for publication.
