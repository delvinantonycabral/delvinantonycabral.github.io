# Delvin Antony Cabral — Personal Portfolio

Official static portfolio website for **Delvin Antony Cabral** (`https://delvinantonycabral.github.io/`), built with semantic HTML5, modern CSS3, and vanilla JavaScript for GitHub Pages.

## Project Structure

```text
/
├── index.html          # Homepage (Hero, Featured Caregiver App, Selected Work, Approach, Domains, Concept Lab, Contact)
├── about.html          # Biography, mindset, problem-solving approach, and pencil-art connection
├── projects.html       # Full case studies in exact sequence (01 Caregiver App → 05 Smart Sonar System)
├── technology.html     # Honest breakdown of technologies used, studied, and currently learning
├── concept-lab.html    # Notebook of concepts, explorations, and experimental ideas
├── contact.html        # Direct email, copy-to-clipboard, mailto composer, GitHub, and Instagram
├── style.css           # Editorial dark theme (#10100F, #F1EEE7, #C6A66A) and responsive layout
├── script.js           # Mobile drawer, email copy button, mailto builder, reduced-motion scroll reveals, auto year
├── robots.txt          # Search engine crawl rules
├── sitemap.xml         # XML sitemap for Google Search Console
├── README.md           # Documentation
└── assets/
    ├── icons/
    │   └── favicon.svg # Custom DAC monogram favicon
    └── images/
        └── og-preview.svg # Social sharing preview graphic
```

## Deploying to GitHub Pages

1. Create or open the repository named `delvinantonycabral.github.io` on GitHub.
2. Upload all files and folders from this directory to the root of the `main` branch.
3. In GitHub repository **Settings → Pages**, set the source to **Deploy from a branch** (`main` / `/ (root)`).
4. Submit `https://delvinantonycabral.github.io/sitemap.xml` in Google Search Console.
